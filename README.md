# Pernas P'ra Andar — landing page

Landing page institucional estática para a Pernas P'ra Andar. Não inclui catálogo, carrinho, pagamentos, contas de cliente ou quaisquer fluxos de comércio eletrónico.

## Publicação

Pode ser publicada no GitHub Pages sem processo de compilação: selecione a raiz do repositório como fonte de publicação.

## Antes de publicar

Preencha em `aviso-legal.html` os dados que não devem ser inventados: morada geográfica, NIF e, se aplicável, matrícula/registo e entidade de resolução alternativa de litígios competente.

O site não instala cookies não essenciais nem recolhe dados por formulário. Se adicionar analytics, vídeo incorporado, chat ou formulário, atualize a política de privacidade e implemente consentimento quando necessário.
